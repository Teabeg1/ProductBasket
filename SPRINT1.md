## 1. 💡 Идея и концепция приложения

**ProductBasket («Совместная корзина продуктов»)** — мобильное приложение для оптимизации и совместного ведения списка покупок внутри семьи или группы людей.

### Ключевая проблематика:
- Хаос при покупках: члены семьи дублируют покупки или забывают купить нужное.
- Непонятно, кто за что отвечает при походе в магазин.
- Для праздников и выездов (пикник, день рождения, Новый год) покупки смешиваются с повседневными товарами.

### Архитектурные принципы и философия продукта:
1. **Полное равенство участников (No Roles / No Hierarchy)**:
   - В семье нет «Администраторов» и «Участников» — все равны.
   - Любой член семьи может пригласить нового участника по коду.
   - Любой член семьи может удалить любого участника (при этом товары исключённого человека автоматически удаляются из всех списков покупок).
2. **Правило распределения ответственности («Куплю я»)**:
   - Товар изначально имеет статус `Не назначено`.
   - Нажатие на свободный товар переводит его в статус `[✓] Куплю я` (закрепляется за текущим пользователем).
   - Повторное нажатие возвращает товар в статус `Не назначено`.
   - Если товар взял другой участник семьи — он блокируется с замком `[🔒] Купит [Имя]`, и изменить его нельзя.
3. **Раздельные корзины для повседневных покупок и мероприятий**:
   - Есть базовая корзина на каждый день (`main`).
   - Для каждого события (мероприятия) создаётся своя изолированная корзина (`eventId`).
   - Корзины не перемешиваются, между ними можно мгновенно переключаться в один клик (`← К общей`).
4. **Визуальный стиль Samokat**:
   - Сочный розовый первичный цвет (`#FF3360`), светло-розовые акценты (`#FFF0F4`), лаймовый статус (`#C8EF5A`), чистые карточки, отсутствие визуального мусора.

## 2. 🎨 Этап дизайна и прототипирования в Figma (`CorzinaUI`)

Разработка велась на базе дизайн-системы в каталоге `c:\IT Projects\VS Code\CorzinaUI`.  
Было спроектировано и реализовано **10 ключевых экранов и модалок**:

1. **Frame 1 — Авторизация (LoginScreen)**:
   - Вход по Email/телефону и паролю.
   - Ссылка на восстановление пароля и переход к регистрации.
   - Переход: если пользователь уже в семье — сразу в приложение (`Main`), если нет — в онбординг (`Onboarding`).
2. **Frame 2 — Регистрация (RegisterScreen)**:
   - Поля: Имя, Email, Пароль, Подтверждение пароля.
   - Чекбокс согласия с условиями сервиса и модальное окно с юридическим соглашением (без упоминания ролей).
3. **Frame 3 — Восстановление пароля (ForgotPasswordScreen)**:
   - Ввод email, валидация.
   - Состояние успешной отправки ссылки для сброса с иконкой подтверждения.
4. **Frame 4 — Корзина продуктов (CartScreen)**:
   - 2-колоночная сетка товаров (Яблоки, Молоко, Майонез, Огурцы, Сыр, Макароны, Сахар, Соль).
   - Счётчик количества (`-` / `кол-во` / `+`).
   - Кнопка урны для мгновенного удаления ошибочно добавленного товара.
   - Плашка с названием активной корзины мероприятия и кнопка возврата `← К общей`.
5. **Frame 5 — Распределение покупок (RolesScreen)**:
   - Инфо-бейдж семьи с микро-аватарками участников и реальным счетчиком людей.
   - Список товаров с кнопками `Не назначено` / `Куплю я` / `[🔒] Купит [Имя]`.
   - Карточка с подсказкой о правиле распределения.
6. **Frame 6 — Мероприятия (EventsScreen)**:
   - Кнопка создания нового события (`+ Создать мероприятие`).
   - Карточки мероприятий с эмодзи, датой, кнопкой удаления.
   - Кнопка `Создать корзину` -> после создания меняется на `Открыть корзину ➔` (открывает отдельную корзину этого события).
7. **Frame 7 — Семейная группа / Онбординг (OnboardingScreen)**:
   - Переключатель: `[Создать семью]` / `[Вступить по коду]`.
   - Генерация случайного 6-значного кода (буквы и цифры вперемешку, без префикса `FAM-`).
   - 6 аккуратных ячеек ввода кода, оптимизированных под экранную клавиатуру Android.
8. **Frame 8 — Расширенные настройки (AdvancedSettingsScreen)**:
   - Тумблеры Push-уведомлений, оповещений о взятых товарах, звука.
   - Смена языка интерфейса (Русский / English).
   - Смена пароля и удаление аккаунта.
9. **Frame 9 — Модальное окно создания мероприятия (CreateEventModal)**:
   - Ввод названия, выбор даты (динамическая текущая дата), выбор эмодзи-иконки события.
10. **Frame 10 — Модальное окно приглашения в семью (AddFamilyModal)**:
    - Показ 6-значного кода семьи, кнопка «Скопировать», кнопка «Поделиться кодом».
    - Лаконичный текст: *«Для входа достаточно ввести этот код»* (любые технические упоминания Frame 7 исключены).

### Floating Tab Bar (Нижний парящий таббар):
- Спроектирован отдельный парящий компонент на 4 вкладки: **Корзина**, **Роли**, **Мероприятия**, **Настройки**.
- Поднят над системными кнопками Android с помощью `useSafeAreaInsets()`.
- Адаптивная вёрстка `flex: 1` — идеально центрируется на любых диагоналях телефонов.

### Ключевые алгоритмические решения:
1. **Генератор случайного семейного кода**:
   ```typescript
   const generateRandomCode = (): string => {
     const chars = '23456789ABCDEFGHJKLMNPQRSTUVWXYZ';
     let result = '';
     for (let i = 0; i < 6; i++) {
       result += chars.charAt(Math.floor(Math.random() * chars.length));
     }
     return result;
   };
   ```
2. **Мульти-корзины (изоляция покупок)**:
   `carts: Record<string, Record<string, CartItem>>` хранит базовую корзину в ключе `main`, а корзины событий — в ключах с соответствующими `eventId`.
3. **Каскадное удаление товаров**:
   При выходе из семьи или удалении участника через кнопку «Удалить из семьи» запускается перебор всех корзин (`main` и все `eventId`), откуда вычищаются все товары, закреплённые за данным пользователем (`assignedToUserId === memberId`).
4. **Снятие выбора и защита от перезаписи**:
   Метод `assignCartItem` гарантирует, что чужие товары не могут быть изменены другим участником, а свой товар можно в любой момент вернуть в «Не назначено».
5. **Бесшовный демо-режим**:
   При отсутствии запущенного бэкенда приложение автоматически переключается на автономный демо-режим без сбоев и крашей.

## 4. 🔍 Результаты полного аудита кода и внесённые исправления

В ходе комплексного анализа каждого файла были обнаружены и устранены следующие недочёты:
- **Синхронизация новых пользователей**: добавлен метод `registerUser` и динамический реестр пользователей. Любой зарегистрированный через экран регистрации пользователь сохраняется и сразу становится активным.
- **Удаление остатков ролей**: очищен юридический текст в `RegisterScreen.tsx`, подтверждено равенство всех участников.
- **Поддержка темной темы во всех инпутах**: `AppInput.tsx`, `RegisterScreen.tsx`, `ForgotPasswordScreen.tsx` переведены на использование динамических цветов `useApp().colors`.
- **Адаптивность таббара**: `FloatingTabBar.tsx` оптимизирован с использованием `flex: 1` для идеального отображения на любых экранах Android и iOS.
- **Динамическая дата событий**: в `CreateEventModal.tsx` захардкоженная дата заменена на динамическую текущую дату с автосбросом.
- **Чистые логи консоли**: убран пугающий стек-трейс `ConnectException` в терминале при запуске без бэкенда.
- **TypeScript верификация**: `npx tsc --noEmit` завершается со статусом `0 errors`.
